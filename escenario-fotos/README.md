## Pestañas
- **En vivo:** hablás por micrófono; para pasarle la palabra al otro, nombralo o tocá su figura.
- **Charla entre ellos:** escribís un tema y conversan solos, turno por turno, con sus voces.
- **Guion:** actúa el guion con la voz del dispositivo (gratis). Tiene modo vertical 9:16.
- **YouTube:** título, descripción, etiquetas e idea de miniatura.

## Publicar en GitHub Pages
1. Creá un repositorio público (por ejemplo `escenario-puente-libertad`).
2. *Add file → Upload files* y subí `index.html`.
3. *Settings → Pages → Branch: main → Save*. A los minutos queda en `https://TU_USUARIO.github.io/escenario-puente-libertad/`.

También sirve arrastrar la carpeta a app.netlify.com/drop.

## Para tener en cuenta
- El micrófono y las voces de ElevenLabs solo andan con la página publicada en https, no abriendo el archivo con doble clic.
- Cada turno gasta créditos de ElevenLabs. Para practicar, usá la pestaña Guion, que es gratis.
- Para grabar el video, filmá la pantalla con otro celular, en horizontal (o en vertical con el modo 9:16).
- Si los personajes no hablan: revisá que los agentes sean públicos (pestaña Security) y, si usás lista de dominios, agregá `TU_USUARIO.github.io`.
- Nunca pongas tu clave de API de ElevenLabs en la página.
